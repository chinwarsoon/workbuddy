Baseline recorded before UI spec §4.2 rev 1.63 — then verified at rev 1.60 / 1.62, §8.2 assertion 21 (Tier 5: 34 passed / 0 failed).
  1. Option B attached table. One .c1-grid, one native <table> with <caption>, <colgroup>, <thead>, <tbody> and scope. No display:contents, no ARIA table roles, no third bordered wrapper. --c1-gutter / --c1-cols drive the grid tracks and the colgroup together, so every month column locks to its curve point.
  2. In-SVG legend above the plot. §4.2 rev 1.62: for an attached table the legend MUST sit above the plotting area, inside the SVG, with yTop sized for the wrapped rows and yBot at the viewBox bottom. It wraps into floor(W / 132) items per row (four series → four bar swatches + four Cum. … line samples). No HTML legend.
  3. Y axis contract. One vertical sc-yaxis-line, five right-aligned Y ticks, and the rotated Cumulative documents side caption. The <thead> row is flush with the plot's X axis; the chart draws no separate X labels.
  4. No-scroll reflow. A ResizeObserver on .c1-plot keeps the SVG width/height, viewBox, data-points[].cx, --c1-cols and <colgroup> in sync at every width and zoom level. No min-width and no horizontal scrollbar. Move From / To and the columns rebuild from the same N.
  5. Tabular typography and hover. tabular-nums on ticks, values and the tooltip. A nearest-datum snap line and a .chart-tip window cover the whole month slice, so there is no 3 px dot dead zone (§4.6). The table is display-only: it does not drive the chart, and no column band or area gradient is drawn.
