In-SVG legend above the plot. §4.2 rev 1.62: for an attached table the legend MUST sit above the plotting area, inside the SVG, with yTop sized for the wrapped rows and yBot at the viewBox bottom. It wraps into floor(W / 132) items per row (four series → four bar swatches + four Cum. … line samples). No HTML legend.
  3. Y axis contract (§4.2 rev 1.64 / 1.65). One vertical sc-yaxis-line, the rotated Documents side caption, and dynamic right-aligned Y ticks: at most 7 intervals / 8 labels for the 300-unit plot, at least ~40 px between major ticks, steps from {1, 2, 2.5, 5} × 10^k, and one grid line per label. Labels, grid lines and refit all read the same axis payload, so the curve fills the chart height. Rev 1.65: the shared maximum comes from the windowed windowData() points, enabled series and Bars toggle, and is recomputed on every repaint; cumulative values stay absolute and are never rebased. No separate bar scale is present. The <thead> row is flush with the plot's X axis; the chart draws no separate X labels.
  4. No-scroll reflow. A ResizeObserver on .c1-plot keeps the SVG width/height, viewBox, data-points[].cx, --c1-cols and <colgroup> in sync at every width and zoom level. No min-width and no horizontal scrollbar. Move From / To and the columns rebuild from the same N.

Owner review decision (2026-11-06), now normative in §4.2 rev 1.63: the hover window is chart-only. The .chart-tip window opens only while the cursor is inside the SVG chart area.
