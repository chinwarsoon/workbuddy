Identified parts (borders)

Border colors follow the C1 border standard (§4.2): panel = slate, board = blue, y-axis = green, plot = amber, table = pink. The legend rows start after a 12-unit left inset from the plot-zone left edge — the edge shared with the y-axis zone — so the first swatch never touches the y-axis side (§4.2 rev 1.84 / I140; the inset matches the 12 px --c3-card-pad token). The One token borders toggle collapses them to one common token. Numbers match the badges on the page. The in-SVG legend sits INSIDE the plot (amber) border, above the plot content — matching C1, where the legend rows live within the plot area (§4.2 rev 1.83, superseding the rev 1.82 above-the-border wording; the production engine uses the same in-SVG legend and retires the HTML legend). §4.2 rev 1.81: the bordered composition is a universal MUST on every dashboard; the Pie / donut view carries the bordered plot zone (6); right angles apply ONLY where borders overlap — the y-axis zone (5) and the plot zone (6) share an edge, so those corners are square, while the gap-separated attached table (7) keeps the 10 px radius. §7.2 rev 1.81: every data table shows ONE outer border — the summary table below is wrapped in a bordered zone.

Gaps are named constants (§6 "no rule hard-codes a value"; §0 spacing scale): --panel-gap (panel↔panel), --panel-pad / --panel-title-gap (card↔adjacent borders), --c3-card-pad (chart/table inset inside card border), --c3-tool-pad (padding around tool row, all four sides), --c3-tool-gap (between control groups inside the tool row), --c3-axis-label-h (x-axis label height, §4.2 rev 1.79), --c3-plot-table-gap (minimized plot→table gap = label height ÷ 3 = 6 px; still scales with the label, keeps the "0" tick clear). One constant change updates all three panels.

Tool-row padding matches across all three panels: --c3-tool-pad = 12 px on all four sides. Tool row 3 sits inside chart card 2 and inside summary table card 9. In the two chart cards a scoped negative margin cancels the outer --c3-card-pad, so the tool padding alone sets the distance to the border; the chart and table keep their 12 px inset. The summary card has no extra padding, so the base rule applies directly.
