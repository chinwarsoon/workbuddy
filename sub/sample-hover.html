Standardized details demonstrated (for spec review):
  • Single component: one .chart-tip class + one .chart-snap class for every chart (replaces the divergent .scurve-tip vs .c2-tip).
  • Tokenized visual contract: surface/border/shadow/radius(8px)/font(11px)/max-width(230px)/z-index(30) all from design tokens; pointer-events:none. (Fixes the C2 hard-coded dark style.)
  • 4-edge clamping: window flips left near the right edge and up near the bottom edge (uses real offsetWidth/Height); never escapes the chart board.
  • Optional snap line: present on axis charts, omitted on the pie — the standard allows per-chart choice.
  • Single delegated binder: one bindChartHover(board) function, applied to every .chart-board; not duplicated per chart.
  • Content separation: each point carries pre-rendered html; the chart's workplan § decides what to show, the standard only presents it.
  • Unified data plumbing: data-points (with cx, optional cy, html) + data-geo ({W,H}) on the board.
  • Trigger: mousemove opens, mouseleave closes (touch/tap variant TBD in spec).
  • Accessibility: role="tooltip"; note for review — keyboard/focus parity still to be specified.
  • KPI cards: the same .chart-tip is applied to KPI cards, but placed below the card (never covers it). Proves the standard is chart-agnostic and that placement can vary by host; per-KPI content (purpose / data source / calculation) is defined in the workplan, not the spec.
  • Totals & percentages: S-curve and bar hovers now append a totals block (one top border) — grand totals plus a percentage where applicable: S-curve shows Total plan / Total actual / Actual % of plan; bars show Total / Resub % / Share of all.
