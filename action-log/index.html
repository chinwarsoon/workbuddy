Perspectives

  • Each icon in the left rail is a perspective. Clicking it swaps both the left panel and the main panel.
  • Actions → tree + action detail. Projects → project list + dashboard. Disciplines → discipline list + breakdown.
  • Reports → report types + chart. Search → saved filters + results. Settings / Help → sections + articles.

Tree navigation (Actions)

  • Click a chevron (▾ / ▸) to expand or collapse a group.
  • Hover a discipline row to reveal its + add-action control; hover an action row to reveal its ✎ edit control.
  • Deleting a project, discipline or action happens in Settings, never in the tree.

Regions — Top bar, Activity bar, Sidebar, Editor, Right panel can each be toggled or resized from Settings (gear icon) or Layout. On narrow screens (≤900px) the ☰ button in the top bar opens the sidebar as a drawer.

Managing lists — Projects, Disciplines, Statuses and Members (names) are added, renamed or deleted only in Settings. The create card and inline editor pick from those lists but never add to them.
