## 2. Legend

### 2.1 Status codes

The **code** is the source of truth; the emoji is a display marker only. Codes follow `AGENTS.md` §5.17c / §26.3.

| Code | Marker | Meaning | Permitted transitions |
|---|---|---|---|
| `OPEN` | 🔴 | Issue raised and accepted, no implementation started | → `APPROVED`, or → `DEFERRED*` / `WONT_IMPLEMENT` / `OPEN_PARTIAL` with rationale |
| `IN_PROGRESS` | 🟣 | Approved work under way | → `RESOLVED`, or → `DEFERRED*` / `OPEN_PARTIAL` with rationale |
| `DEFERRED` | ⏸️ | Parked with a recorded rationale | → `OPEN` / `APPROVED` when work resumes |
| `DEFERRED_STUDY` | 🔍 | Parked pending investigation | → `OPEN` / `APPROVED` |
| `DEFERRED_REVIEW` | ⏳ | Parked pending an external review or decision | → `OPEN` / `APPROVED` |
| `WONT_IMPLEMENT` | ⛔ | Rejected; kept for history | reopen as `OPEN` only on new evidence |
| `OPEN_PARTIAL` | 🟠 | Partly delivered; a named remainder is still open | → `RESOLVED` when the remainder lands |
| `APPROVED` | 🔵 | Task definition and approval recorded, not started | → `IN_PROGRESS`, or → `DEFERRED*` |
| `RESOLVED` | ✅ | Tasks and closure criteria verified | → `ALIGNED` after workplan/document alignment |
| `ALIGNED` | 🔗 | Resolved **and** the workplan/documentation updated to match | terminal |

Transitions that change a status need recorded approval evidence (§26.6): `Approved: <date> by <author>`.

### 2.2 Severity markers

| Marker | Severity | Meaning |
|---|---|---|
| 🔴 | Critical | blocks delivery or correctness |
| 🟠 | High | major capability or defect |
| 🟡 | Medium | visible gap with a workaround |
| 🟢 | Low | polish, naming or documentation |
| 🔷 | Deferred | parked; severity re-set when re-opened |

### 2.3 Legacy vocabulary → canonical code

The recovered register (pre-governance) used its own wording. It is preserved in every row **and** mapped here;
nothing was rewritten.

| Recovered wording | Canonical code |
|---|---|
| `Implemented <date>` / `Done (<date>)` / `Closed (<date>)` | `RESOLVED ✅` |
| `Logged` (nothing delivered yet) | `OPEN 🔴` |
| `Logged` / `Piloted` with part already shipped under another issue | `OPEN_PARTIAL 🟠` |
| `Deferred` (a decision parks it) | `DEFERRED ⏸️` |
